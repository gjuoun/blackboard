Blackboard

把方案评审，搬回文档里。

划一句，批一句；你的 agent 用同一条 CLI 接话，改到定稿。

开始使用 GitHub ↗ English
$npm install -g blackboard
$blackboard open docs/plan.md

也可以用 bun：bunx blackboard open docs/plan.md

文档页：划一段文字、写一句批注；agent 在 shell 里回话，改动实时上屏。

首页

每个会话就是磁盘上的一个 markdown 文件，在哪个仓库、哪条分支一目了然。点高亮定位评论，点评论跳回正文。

它能做什么

  • 会话 — 磁盘上任意 markdown 文件都能开，浏览器里直接看到它在哪个仓库、哪条分支。
  • 正文批注 — 划选一段话写批注，回复平铺展示，可标记解决、也可重新打开。
  • 实时视图 — 文件一改页面就刷新，高亮始终跟着它标注的段落。
  • 给 agent 的 CLI — pi、Claude Code、Codex，任何会用 shell 的 agent 都能读评论、回评论。
  • 地道的 markdown — GFM 表格（表头吸顶）、标题锚点、目录，front matter 渲染成表格。
  • 离线 mermaid — 图表用内置库在浏览器里渲染，断网也能看。
  • 本地且安全 — 只绑 127.0.0.1，只服务注册过的文件，每次请求都重新校验。
  • 一键复制 — 未解决的评论复制成 markdown，粘到哪儿都能接着聊。

给 agent 的 CLI

blackboard open     <file> [--no-browser]                # 打印 "<id>  <url>"
blackboard sessions [--json]                             # id、标题、位置、分支、未解决评论
blackboard comments <session> [--all] [--json]
blackboard reply    <session> <comment-id> "text"
blackboard resolve  <session> <comment-id>               # 或者：reopen
blackboard comment  <session> --quote "passage" "note"
blackboard wait     <session> [--timeout 30m]            # 阻塞等待人的新评论

CLI 直接读写 ~/.blackboard 下的文件，和 web 应用共用一把锁——应用开着关着都能用，开着的页面会实时跟着变。
